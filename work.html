01 / Anonymised paid client deployment

AWS environment for a small-business application

A paid engagement to build the AWS environment for a small-business application and its internal system, with the client kept anonymous.

The environment had to host the application reliably, keep its data recoverable, control who and what could reach it, and make problems visible early.

I configured it end to end: EC2 compute and RDS for the application, S3 for static website hosting and document storage, VPC networking to separate the public and private tiers, IAM policies to scope access, deployment tooling, basic backups, and CloudWatch monitoring.

EC2 · RDS · S3 · VPC · IAM · CloudWatch

Client identity is withheld by agreement. No performance figures are claimed. Only approved, non-confidential project information is shared publicly.

Student essay evaluation workflow
